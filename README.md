\# University Request, Complaint and Suggestion System



A full-stack web application developed to manage university requests, complaints, suggestions and information requests through a centralized digital platform.



The system allows applicants to submit and track applications, while authorized staff members can review, assign, forward, answer and close requests.



\## Features



\- Submit requests without registration

\- Email verification after submission

\- Application tracking with tracking code and email

\- Dynamic category and unit selection

\- Secure staff authentication

\- Role-based access control

\- Assign and forward applications

\- Answer, close or reject applications

\- Unit and category management

\- Email notification system



\## Tech Stack



\- Next.js

\- React

\- TypeScript

\- Tailwind CSS

\- PostgreSQL

\- Prisma ORM

\- JWT Authentication

\- bcrypt

\- Resend
